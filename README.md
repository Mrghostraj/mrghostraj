## 🚀 Featured Projects

### 🛡️ Android Malware Detection using Hybrid Deep Learning

A deep learning based malware classification system that represents malware binaries as images and classifies them using a hybrid **VGG16 + ResNet50** architecture.

**Highlights**
- Worked with malware datasets including **Malimg, MaleVis and Microsoft BIG 2015**
- Developed a hybrid CNN architecture combining VGG16 and ResNet50
- Applied transfer learning and fine-tuning for improved classification
- Achieved approximately **98%+ classification accuracy** on benchmark experiments
- Evaluated the model using Accuracy, Precision, Recall and F1-score

**Tech:** `Python` `TensorFlow` `Keras` `CNN` `VGG16` `ResNet50` `OpenCV`
